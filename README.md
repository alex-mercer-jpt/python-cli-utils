# Python CLI Utilities Project

Учебный проект, демонстрирующий навыки программирования на Python и работу с модульной архитектурой. 

## 🛠 Технологии и навыки:
- **Python 3.10+**
- **Модульная архитектура:** разделение кода на логику и интерфейс (CLI).
- **Продвинутые функции:** декораторы (кэширование, повторение), генераторы, рекурсия, замыкания.
- **Области видимости:** работа с `global` и `nonlocal`.
- **Встроенные функции:** `map`, `filter`, `lambda`, `zip`, обработка строк и коллекций.
- **Обработка исключений:** защита от некорректного пользовательского ввода (try/except).

## 🚀 Как запустить:
1. Клонируйте репозиторий.
2. Запустите главный файл:
```bash
python main.py
